# Security Policy

## Supported Versions

StudyOS is under active development. Security fixes are applied to the latest version on the default branch unless a release explicitly states otherwise.

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for vulnerabilities involving authentication, authorization, exposed credentials, personal data, Firebase security rules, or third-party integrations.

Use GitHub's private security advisory flow for this repository when available, or contact the maintainer privately through the contact information on the GitHub profile.

A useful report should include:

- A clear description of the issue and potential impact
- The affected feature or component
- Reproduction steps
- Relevant logs or screenshots with sensitive information removed
- Any suggested mitigation, if known

Please avoid accessing, modifying, or retaining data that does not belong to you while validating a report.

## Scope

Security-sensitive areas include Firebase Authentication, Firestore and Storage rules, Cloud Functions, OAuth integrations, role-based access controls, API credentials, and user-generated academic data.
